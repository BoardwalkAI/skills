The files on [boardwalkai.com](https://boardwalkai.com) are the source. This repo is the published copy. When a site file changes, update the matching file here so the two do not drift.

The Cursor Marketplace plugin is [BoardwalkAI/cursorplugin](https://github.com/BoardwalkAI/cursorplugin). It points at the hosted MCP and carries a short skill. The long Cursor instructions are `cursor.md` in this repo.
